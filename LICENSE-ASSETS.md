# Licence of the Glim assets

The BurnMon code is MIT, see `LICENSE`. That includes the code of the lamp.

One thing is not under the MIT licence: the drawing of Glim. That is the output of
`internal\lamp` (the SVG Glim draws, the poses, the demo picture and the week card) and the
files under `assets\glim\`.

The drawing is Copyright 2026 Wilco de Tree, ZeroNonsense.dev, all rights reserved.

A fork of BurnMon may use the code under the MIT licence. A fork draws its own character for
its lamp, not a drawing that copies Glim. Please give that character its own name too, so
users can tell the two lamps apart.

One-liners that people send in by pull request or issue are MIT and are credited in
`internal\lamp\CREDITS.md`. See the section Suggest a line in `cmd\burnmon-dev\README.md`.
